\title{On-Device Reasoning for GPS-Denied Drones:\\

\begin{abstract}
We present a navigation stack for GPS-denied micro-drones that fuses
monocular visual SLAM, a single-beam 1D range sensor, and a nonlinear
model predictive controller (MPC), and is supervised by an on-device
small language model (Gemini Nano). The 1D range sensor provides
metric-scale recovery for monocular SLAM and a hard floor on ground
clearance; the MPC is perception-aware, softly preferring trajectories
that preserve feature visibility and beam validity; Gemini Nano runs
at 1--5\,Hz as an advisory layer that adapts mission-level behavior
when SLAM degrades. We evaluate the system in simulation across four
scenarios and four ablations, reporting absolute trajectory error,
mission completion rate, minimum clearance, and on-device latency.
\end{abstract}
